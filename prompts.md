# Scribbly Notes — Build Prompts & Specification Log

1. **Core Concept:** Build an offline-first digital notebook maker (`Scribbly Notes`) using HTML, CSS, and Vanilla JavaScript that converts typed study notes into handwritten-style pages.
2. **Visual Direction:** Warm cream and beige background (`#f5efe6`), soft brown accents (`#8c6239`), off-white paper sheets (`#fffdf9`), subtle shadows, and responsive desktop/mobile layout.
3. **Typography & Realism:** Local `@font-face` support for Casual, Neat, and Classic handwriting styles paired with deterministic per-word variations (vertical baseline drift, slight rotation, scale, and spacing).
4. **Pagination & Export:** Line-height-locked pagination (`24` lines/page) with Previous/Next controls, 2x Canvas PNG export for the active page, and multi-page selectable-text PDF export.
